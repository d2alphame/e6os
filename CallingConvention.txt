The Calling Convention of e6

When making a call
1.	First number goes into RAX, second number goes into RDX.
2.	First string goes into RSI, second string goes into RDI.
3.	First buffer goes into RBX, second buffer goes into RBP.
4.  Parameters for counting, lengths, or sizes go into RCX. 
5.	If there are too many of a given parameter type, then pass all parameters in a buffer pointed to in RBX.
6.	When there is an error, the carry flag is set, RAX contains the error code and RSI points to the error string. RDX may contain a number that represents other kind of information.
7.	The carry flag is cleared on success.
8.	RAX, RBX, RCX, RDX, RSI, RDI, and RBP are volatile. The callee may change them.
9.	R8 - R15 are preserved across calls. The callee must preserve these
10.	RSP must be preserved by the callee.
11.	The stack is used for making calls and as temporary working space.
12.	Arrays and structs/records are treated as buffers so they are passed in RBX/RBP.

When returning from a call
1.	Returning from a call works the same way as making a call. Return the first number in RAX, the second number in RDX.
2.  Use RCX to return counting values, e.g. number of bytes in a buffer or length of a string.
3.	Return first string in RSI and second string in RDI.
4.	Return the first buffer in RBX and the second in RBP.
5.	If there are too many return values of a given type, return all values in a buffer pointed to by RBX.
6.	On error, set the carry flag, put the error code in RAX and the error string in RSI.
7.	Clear the carry flag on success
8.	RAX, RBX, RCX, RDX, RSI, RDI, and RBP are volatile. These registers may be used as the programmer sees fit.
9.	R8-R15 must be preserved.
10.	RSP must be preserved.
11.	The stack is used as local working space and for making calls.

Data types.

1. Strings
Tiny string: A string whose length fits in single byte, i.e. of length 0 to 255 bytes
Small string: A string whose length fits in 2 bytes, i.e. of length 0 to 65545 bytes
Big string: A string whose length fits in 4 bytes, i.e. of length 65,536 to 4,294,967,296 bytes
Huge string: A string whose length is greater 4,294,967,296 bytes.
RCX string: A string whose length is specified in RCX.
Null-terminated string: A string terminated by null.
Value-terminated string: A string terminated by a specified value.

2. Numbers
Byte: An 8-bit unsigned, number
Signed byte: An 8-bit signed, number
Word: A 16-bit unsigned, number
Signed word: A 16-bit, signed number
Double word: A 32-bit, unsigned number
Signed double word: A 32-bit, signed number
Quad word: A 64-bit, unsigned number
Signed quad word: A 64-bit, signed number

Arrays and buffers.
